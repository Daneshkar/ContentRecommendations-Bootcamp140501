# Codex Workspace Instructions

At the beginning of every new task or chat in this repository, read
`.codex-memory/PROJECT_CONTEXT.md` completely before planning or changing files,
if that local file exists.

After a material project decision, implementation milestone, commit, branch
change, migration, or GitHub issue/PR status change, update that memory file so
the next chat can resume from the actual current state.

The `.codex-memory/` directory is local working memory. Never stage or commit
its contents.
